# موقع قص ملفات PDF الاحترافي

موقع ويب احترافي لقص وتقسيم ملفات PDF مباشرة في المتصفح بدون الحاجة لرفع الملفات إلى أي خادم.

## المميزات

- **آمن 100%**: جميع العمليات تتم محلياً في متصفحك، لا يتم رفع أي ملفات إلى خوادم خارجية
- **سريع**: معالجة فورية للملفات دون انتظار التحميل أو التنزيل
- **خصوصية تامة**: ملفاتك تبقى على جهازك فقط
- **واجهة عربية**: تصميم كامل باللغة العربية مع دعم الاتجاه من اليمين لليسار
- **متجاوب**: يعمل بشكل ممتاز على جميع الأجهزة (كمبيوتر، لوحي، هاتف)
- **مجاني**: لا حاجة للتسجيل أو الدفع

## كيفية الاستخدام

1. افتح الموقع في متصفحك
2. اسحب ملف PDF وأفلته في المنطقة المخصصة، أو انقر لاختيار ملف من جهازك
3. اختر الصفحات التي تريد قصها:
   - انقر على كل صفحة individually
   - استخدم أزرار التحديد السريع (الكل، فردية، زوجية)
   - حدد نطاق صفحات باستخدام حقول "من" و "إلى"
4. انقر على زر "قص الصفحات المحددة"
5. انتظر حتى تتم المعالجة
6. حمل الملف الجديد أو ابدأ من جديد

## التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التصميم والأنيميشن
- **JavaScript**: المنطق والوظائف
- **PDF.js**: مكتبة لعرض صفحات PDF
- **PDF-Lib**: مكتبة لمعالجة وتعديل ملفات PDF

## تشغيل الموقع محلياً

### الطريقة 1: باستخدام Python

```bash
cd pdf-cutter
python3 -m http.server 8080
```

ثم افتح المتصفح على: `http://localhost:8080`

### الطريقة 2: باستخدام Node.js

```bash
cd pdf-cutter
npx serve
```

### الطريقة 3: فتح الملف مباشرة

يمكنك فتح ملف `index.html` مباشرة في المتصفح، لكن بعض الميزات قد لا تعمل بشكل صحيح بسبب سياسات الأمان في المتصفحات.

## هيكل الملفات
